# airplane-sunshang

Aircraft tire damage visualization and management system for airport ground crew.

Built with React 19 + TypeScript + Vite + Tailwind CSS + shadcn/ui.

## Tech Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- Framer Motion
- React Router v7

## Development

```bash
npm install
npm run dev
```

## Deployment

Auto-deployed to GitHub Pages via GitHub Actions on push to `main` or `dev`.
